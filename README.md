# Website Profil SMP Negeri 3 Cibungbulang

Website profil resmi SMP Negeri 3 Cibungbulang, Kabupaten Bogor.

## Fitur Utama
- **Frontend Publik**: Beranda, Profil Sekolah, Visi & Misi, Sambutan Kepala Sekolah, Berita & Kegiatan, Prestasi Siswa, Ekstrakurikuler, dan SDM Guru & Staf.
- **Admin Panel**: Manajemen konten dinamis (Berita, Slider, Prestasi, Ekskul, Sambutan, Guru/SDM).

## Teknologi
- [Next.js](https://nextjs.org/) (App Router)
- [Prisma ORM](https://www.prisma.io/) & SQLite
- Vanilla CSS Modern
